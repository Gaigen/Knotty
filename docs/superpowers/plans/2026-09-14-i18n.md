# Knotty i18n (next-intl) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить двуязычный UI (ru по умолчанию, en) через `next-intl` без поломки существующих URL и пользовательского контента.

**Architecture:** `next-intl` с `localePrefix: 'as-needed'` — русский остаётся на `/`, английский на `/en/...`. Локаль хранится в cookie `NEXT_LOCALE` и синхронизируется с профилем пользователя (опционально, фаза 3). Системные строки (кнопки, ошибки валидации, лейблы enum) — в `messages/{locale}.json`. Пользовательский контент (названия задач, статусы проекта, комментарии) **не переводится**.

**Tech Stack:** Next.js 16 App Router, `next-intl` ^4.3.4 (уже в `package.json`), React 19, TypeScript.

## Global Constraints

- Дефолтная локаль: `ru` (текущее поведение продукта).
- Вторая локаль на старте: `en`.
- Не ломать query-based routing (`/?project=...&tab=graph`).
- `DEFAULT_STATUSES` при создании проекта — данные БД, не UI; перевод только шаблонов при **создании**, не миграция существующих.
- MCP-сервер (`mcp-server/`) — отдельный план (фаза 6), не блокирует UI.
- Issue GitHub: #12.

- [ ] **Step 1: `src/i18n/routing.ts`**

```ts
import { defineRouting } from 'next-intl/routing'

export const routing = defineRouting({
  locales: ['ru', 'en'],
  defaultLocale: 'ru',
  localePrefix: 'as-needed',
  localeCookie: {
    name: 'NEXT_LOCALE',
    maxAge: 60 * 60 * 24 * 365,
  },
})

export type Locale = (typeof routing.locales)[number]
```

- [ ] **Step 2: `src/i18n/request.ts`**

```ts
import { getRequestConfig } from 'next-intl/server'
import { routing } from './routing'

export default getRequestConfig(async ({ requestLocale }) => {
  let locale = await requestLocale
  if (!locale || !routing.locales.includes(locale as 'ru' | 'en')) {
    locale = routing.defaultLocale
  }
  return {
    locale,
    messages: (await import(`../../messages/${locale}.json`)).default,
  }
})
```

**Files:**

```tsx
'use client'
import { useLocale } from 'next-intl'
import { useRouter, usePathname } from '@/i18n/navigation'
import { routing } from '@/i18n/routing'

export function LocaleSwitcher() {
  const locale = useLocale()
  const router = useRouter()
  const pathname = usePathname()
  return (
    <select
      value={locale}
      onChange={(e) => router.replace(pathname, { locale: e.target.value as 'ru' | 'en' })}
    >
      {routing.locales.map((l) => (
        <option key={l} value={l}>{l === 'ru' ? 'Русский' : 'English'}</option>
      ))}
    </select>
  )
}
```
