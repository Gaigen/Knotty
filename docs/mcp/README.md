# MCP для таск-трекера

MCP-сервер даёт AI-ассистентам доступ к **REST API** приложения: проекты, задачи, статусы — через tools с префиксом из env (по умолчанию `tb_`).

> Рабочее название продукта в UI может меняться; в MCP используются нейтральные `task-board` / `tb`, настраиваемые через переменные окружения.

## Зачем

| Сценарий | Пример |
|----------|--------|
| Планирование в чате | «Создай баг в проекте DDTSS» |
| Сводка | «Список просроченных задач» |
| Автоматизация | Скрипт + тот же Bearer-токен |

## Аутентификация

**Bearer API-токен** (не cookie):

1. В приложении: **Аккаунт → API-токены → Создать**
2. Скопировать токен один раз → `TASKBOARD_API_TOKEN` в env MCP

## Env MCP-сервера

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `TASKBOARD_API_URL` | `http://localhost:3000` | URL API |
| `TASKBOARD_API_TOKEN` | — | Bearer-токен |
| `MCP_TOOL_PREFIX` | `tb` | Префикс tools (`tb_list_tasks`) |
| `MCP_SERVER_NAME` | `task-board` | Имя сервера в MCP |

В приложении: `API_TOKEN_PREFIX` (по умолчанию `tb`) — префикс самого токена.
